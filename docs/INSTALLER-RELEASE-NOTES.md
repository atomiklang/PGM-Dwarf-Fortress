# Download / Télécharger — assistant beta 4

## English

- **Windows 64-bit:** download and open `PGM-Installer-Windows-0.1.0-beta.4.exe`.
- **Native Linux x86-64:** download `PGM-Installer-Linux-0.1.0-beta.4.bin`, allow execution in the file properties, then open it. Alternatively, extract the `.tar.gz` and open `PGM-Installer`.
- No Python installation needed. Install Dwarf Fortress 53.17, matching DFHack 53.17-r1 and the Workshop subscriptions first, then close the game.

[English installation guide](https://github.com/atomiklang/PGM-Dwarf-Fortress/blob/main/docs/INSTALL.en.md) · [PGM Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3841490386) · [Modpack collection](https://steamcommunity.com/sharedfiles/filedetails/?id=3817551587)

Prepare compatibility variants and install Normal/Full presets through the assistant. Linux translation content19 is included; an existing managed Linux installation can be updated without the old assistant. Personal changes are protected and original backups retained. Changed presets require restore then reinstall. A power failure during migration needs assisted recovery; keep the backup folder.

**Windows translation is experimental, optional and off by default.** Game tests were performed under Proton GE 11-12 only. Native Windows gameplay, Linux rendering parity and complete DF-FR compatibility are not validated. Choose DF-FR or native PGM translation; the latter is refused if DF-FR is detected. Quests and presets are independent.

The actual installers were built and opened on Ubuntu 22.04 and Windows Server 2022. Embedded data matched their build manifests. Linux requires glibc 2.35 or newer. This verifies installer startup, not a complete game session. Executables have no commercial signing certificate.

Updates: the assistant downloads a newer verified application; open that application and use its installation/update buttons. Downloading alone does not replace the application or update game files. Steam updates the Workshop mod.

## Français

- **Windows 64 bits :** télécharger puis ouvrir `PGM-Installer-Windows-0.1.0-beta.4.exe`.
- **Linux natif x86-64 :** télécharger le `.bin`, autoriser son exécution dans les propriétés puis l’ouvrir. Autre possibilité : extraire le `.tar.gz` et ouvrir `PGM-Installer`.
- Aucun Python à installer. Installer d’abord le jeu 53.17, DFHack 53.17-r1 et les abonnements Workshop, puis fermer le jeu.

[Guide Windows](https://github.com/atomiklang/PGM-Dwarf-Fortress/blob/main/docs/INSTALL-WINDOWS.fr.md) · [Guide Linux](https://github.com/atomiklang/PGM-Dwarf-Fortress/blob/main/docs/INSTALL-LINUX.fr.md)

L’assistant prépare les variantes et les presets Normal/Full. La traduction Linux19 est incluse, avec mise à jour des installations déjà gérées et conservation des sauvegardes originales. Les modifications personnelles empêchent leur remplacement. Pour changer les presets gérés, restaurer puis installer. Après une coupure pendant une migration, conserver le dossier de sauvegarde et demander une récupération.

La traduction Windows est **expérimentale, facultative et désactivée par défaut** ; essais du jeu sous Proton uniquement. Choisir DF-FR ou la traduction native PGM, refusée si DF-FR est détecté. Une partie Windows native et la parité Linux restent à valider.

Les exécutables ont été construits, contrôlés et ouverts sur leurs systèmes de construction Windows/Linux. Linux demande glibc 2.35 ou plus. Ces contrôles ne constituent pas une partie complète. Utiliser le nouvel assistant téléchargé puis ses boutons pour mettre les fichiers à jour ; le téléchargement seul ne change rien au jeu.
