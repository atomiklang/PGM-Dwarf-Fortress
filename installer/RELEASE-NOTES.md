## Download / Télécharger

- **Windows x64:** download and run **PGM-Installer-Windows-0.1.0-beta.1.exe**. No Python installation needed.
- **Linux x86-64:** download **PGM-Installer-Linux-0.1.0-beta.1.tar.gz**, extract it, then open **PGM-Installer**. No Python installation needed. Requires glibc 2.35 or newer; built and smoke-tested on Ubuntu 22.04. Other distributions still need user testing.

This experimental assistant prepares local modpack variants, installs/restores Normal and Full presets, and installs/restores the **native Linux 53.17 French translation**. Install the game, matching DFHack and Workshop subscriptions through Steam first. Quests are distributed by the PGM Steam item.

**Windows:** native PGM game translation is not included. The optional DF-FR route remains in the Windows guide. A full Windows playthrough has not been validated.

**Updates:** this beta checks for and downloads new installer executables with SHA-256 verification. Open the downloaded version to use it. Automatic replacement of the application and automatic dictionary updates are not implemented yet. Steam continues to update Workshop mods.

**Windows :** téléchargez puis ouvrez le **.exe**. **Linux :** téléchargez l’archive **.tar.gz**, extrayez-la puis ouvrez **PGM-Installer**. Il n’est pas nécessaire d’installer Python. Le fichier **.bin** Linux est aussi disponible pour les téléchargements directs depuis l’assistant ; l’archive reste le choix conseillé pour une première installation.

L’assistant prépare les variantes locales du modpack, installe/restaure les presets et installe/restaure la traduction Linux native. Les mods, les quêtes et DFHack restent distribués par Steam. Les fichiers précédents sont sauvegardés et les fichiers modifiés localement sont protégés.

**Bêta :** la traduction native PGM Windows n’est pas incluse. La mise à jour automatique du dictionnaire et le remplacement automatique de l’application restent à développer. Le bouton de mise à jour télécharge une nouvelle version vérifiée à ouvrir ensuite. Les exécutables ne sont pas signés avec un certificat commercial.
